# Windows 11 Desktop

An interactive desktop environment featuring functional notepad and paint applications with draggable and maximizable windows.

## Overview

The application creates a simulated desktop environment using HTML and CSS for layout and styling. JavaScript handles window management operations including dragging, maximizing, minimizing, and launching inner apps.

## Highlights

- Draggable and resizable windows
- Fully functional text notepad application
- Interactive drawing canvas paint app
- Windows 11 inspired taskbar and styling
